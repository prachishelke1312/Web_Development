# How to Run the Programs

## HTML/CSS/JavaScript

1. Open the project folder in VS Code.
2. Save files with `.html` extension.
3. Open the file in any browser.

## PHP Programs

1. Install XAMPP or WAMP.
2. Place PHP files inside the `htdocs` folder.
3. Start Apache server from XAMPP Control Panel.
4. Open browser and run:

   ```text
   http://localhost/foldername/file.php
   ```
